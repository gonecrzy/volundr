# Gemini Prompt Contract Selection

Prompt selection used the eligible S0/H0 pair and the six frozen selection
packets. T0 preserved the current substantive provider prompt builders. T1
made provider ownership and invariants explicit.

The final resumed matrix completed 12/12 operations for both candidates, but
T0 passed 11/12 and T1 passed 7/12. Neither candidate therefore cleared the
universal quality floor. T2 and T3 were not run because the completed
comparison exposed substantive provider instability rather than a bounded
checklist-only defect.

The current prompt winner is not a production rollout authorization. The
formal contracts and adapter remain gated by holdout evidence.
