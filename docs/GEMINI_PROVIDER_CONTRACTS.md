# Gemini Provider Contracts

Frozen experiment-scoped contracts are stored under the study `contracts/`
directory and mirrored in the required report files. They describe provider
meaning, allowed representation variation, forbidden omissions or inventions,
canonical semantic projections, and ownership boundaries.

Provider-owned meaning includes requirements, clarification decisions,
components, features, relationships, geometry operations, local names, and
bounded repairs. Volundr owns lifecycle IDs, provenance, persistence IDs, slot
IDs, result symbols, source assembly, worker submission, artifacts, topology,
verification, and candidate resolution.

The geometry contract preserves provider-owned CadQuery source without using
the current parser. Missing meaning, invalid APIs, undefined names, and
ambiguous mappings fail closed. The contracts are not production contracts
until a future holdout clears the universal floor.
