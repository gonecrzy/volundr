# Gemini Flash Lite before/after comparison

Reports compare requirement, clarification, planning, response structure,
execution, topology, verification, and final-outcome consistency separately.
Primary metrics include valid source, worker reach, valid topology, measured
feature evidence, candidate readiness, and three-run consistency. Provider
calls, repair calls, tokens, and latency are secondary metrics.

The comparison is explicitly not a controlled provider pair because cleanup
separates baseline and validation.
