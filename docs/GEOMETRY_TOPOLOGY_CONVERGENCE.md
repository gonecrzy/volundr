# Geometry and topology convergence

This document is the current boundary between worker/topology success and
feature/requirement verification. A valid one-solid artifact proves only the
authoritative topology invariant; it does not prove that a named handle,
opening, slot, compartment, divider, or notch exists or satisfies its target.

The geometry-slot path now records compact source-to-result traces for
provider-owned feature functions: input/output shape hashes and summaries,
solid counts, volume, bounds, operation category, execution state, and shape
change. Final feature evidence separately measures the generated output and
maps the result to the existing requirement findings. Missing traces,
ambiguous traces, no-effect functions, absent final geometry, and failed
measurements remain explicit states rather than successful candidates.

The generic measurement boundary covers connected integral features,
through-openings, slots, cavities/compartments, and one-connected-output
topology. It is descriptor-driven and does not contain portable-holder or
desktop-organizer verifier classes. A feature repair is limited to one
identified feature, one provider operation, preserved unaffected hashes, and
mandatory final remeasurement.

The frozen portable-holder and desktop-organizer audit is in
`DETERMINISTIC_FEATURE_VERIFICATION.md`. The focused live result is in
`FEATURE_VERIFICATION_LIVE_EVALUATION.md`. The selected planning priority is
generic final geometry verification convergence for traced features; no
product-family generation fix or same-run correction was applied.
